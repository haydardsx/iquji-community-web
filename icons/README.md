# @iquji-community/web-icons

[简体中文](README.zh-CN.md)

React icons with explicit decorative and accessible label options.

```sh
npm install react@19.2.4 react-dom@19.2.4 @iquji-community/web-icons
```

```tsx
import { IqujiIcon } from "@iquji-community/web-icons";

export function SearchIcon() {
  return <IqujiIcon decorative={false} name="search" label="Search" />;
}
```
